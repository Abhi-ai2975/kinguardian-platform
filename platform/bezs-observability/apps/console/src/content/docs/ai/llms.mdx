# LLMs.txt

Watcher24 publishes a `/llms.txt` file at the root of this site. It gives AI assistants a concise, structured summary of the product so they can help you integrate it without needing to read every doc page.

## What is llms.txt?

[llms.txt](https://llmstxt.org) is an emerging standard (similar to `robots.txt`) for providing AI-friendly documentation. Place a plain-text file at `/llms.txt` describing your product, its APIs, and usage patterns.

AI assistants that support the standard will automatically fetch this file when they detect your domain in a conversation — giving them accurate, up-to-date context.

## Watcher24's llms.txt

Our `/llms.txt` covers:

- What Watcher24 is and what problems it solves
- SDK packages and their install commands
- Core API methods with signatures
- Event types and when to use each
- Environment variable names
- Common integration patterns

You can view or fetch it directly:

```bash
curl https://watcher24.io/llms.txt
```

Or use the **Open in Claude** button on any doc page to pre-load the current page's markdown.

Add to your `.cursorrules` or `copilot-instructions.md`:


## Format reference

Our `llms.txt` follows this structure:

```
# Watcher24

> Real-time observability and audit logging platform.

Watcher24 ingests telemetry (logs, metrics, traces, audit events) from SDKs,
processes them, and displays them on a realtime dashboard.

## SDKs

- JavaScript / Node.js: `@watcher/node`, `@watcher/browser`, `@watcher/react`, `@watcher/nextjs`
- Python: `watcher-sdk` (pip / uv)

## Core methods

audit(message, options)  — compliance trail for user actions
log(severity, message)   — application log events
trace(message, options)  — distributed trace spans
metric(message, options) — numeric measurements

## Docs

- [Quickstart](/docs/quickstart)
- [JavaScript SDK](/docs/sdks/javascript)
- [Python SDK](/docs/sdks/python)
- [Event Types](/docs/concepts/events)
- [API Reference](/docs/api/ingestion)
```

## For tool builders

If you are building a developer tool that integrates with Watcher24, add our `llms.txt` URL to your context loading pipeline so users get correct SDK usage out of the box:

```typescript
const WATCHER_DOCS_URL = "https://watcher24.io/llms.txt";

async function loadWatcherContext(): Promise<string> {
  const res = await fetch(WATCHER_DOCS_URL);
  return res.text();
}
```
